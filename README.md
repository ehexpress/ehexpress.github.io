# EH Express Transportes

Pacote final do site institucional, pronto para GitHub Pages.

## Arquivos
- `index.html`
- `404.html`
- `README.md`
- `assets/`
  - `logo-eh-express.svg`
  - `favicon.svg`
  - fotos reais dos serviços

## Como publicar
1. Extraia o arquivo ZIP.
2. Entre no repositório `ehexpress.github.io`.
3. Envie `index.html`, `404.html`, `README.md` e a pasta `assets/` para a raiz do repositório.
4. Faça o commit.
5. Em `Settings > Pages` configure:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
6. Aguarde a publicação.
