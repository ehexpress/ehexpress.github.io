# EH Express Transportes

Site institucional estático para GitHub Pages.

## Publicação
Envie `index.html` e a pasta `assets/` para a raiz do repositório `ehexpress.github.io`.

## Estrutura
- `index.html`
- `assets/` — fotos reais dos serviços

## GitHub Pages
Em Settings > Pages:
- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

O endereço será:
https://ehexpress.github.io/
