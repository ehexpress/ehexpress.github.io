# EH Express Transportes

Versão final do site institucional, pronta para GitHub Pages.

## Estrutura
- index.html
- 404.html
- assets/
  - logo.svg
  - favicon.svg
  - fotos reais dos serviços

## Publicação
1. Extraia o ZIP.
2. Envie `index.html`, `404.html` e a pasta `assets` para a raiz do repositório `ehexpress.github.io`.
3. Faça o commit.
4. Em Settings > Pages:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
5. Aguarde a publicação.

Site:
https://ehexpress.github.io/
