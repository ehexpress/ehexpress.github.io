# EH Express Transportes

Site estático pronto para GitHub Pages.

## Publicar
Envie todos os arquivos e a pasta `assets/` para a raiz do repositório `ehexpress.github.io`.

Em **Settings > Pages**:
- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

Endereço:
https://ehexpress.github.io/
